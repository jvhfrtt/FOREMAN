# 世界观版使用说明（含测试剧情）

> 监工台 FOREMAN 的世界观版用法。以本次测试用世界《神战之后》为完整示例：先讲工具怎么用，再附测试剧情全记录，最后是通用性测试结论。

---

## 一、这是什么

**世界观版 = FOREMAN 插件（不改）+ lore-check 门禁 + 一套格式约定。**

它不做“文学评判”，只做**可执行的一致性检查**：拦吃书、名字漂移、时间线倒退、引用断裂、伏笔丢失、神域膨胀。门禁能判“一不一致”，不能判“好不好”。

| 代码版席位 | 世界观版席位 | 职责 |
|---|---|---|
| Coder | 执笔者 | 写设定条目/档案/故事草稿 |
| Reviewer | 设定审查 | 找前后矛盾、吃书、OOC |
| Builder | 设定门禁官 | 跑 lore-check 出证据 |
| Nitpicker | 设定挑刺 | 专找时间线/命名/体系漏洞 |
| Archivist | 设定档案 | 伏笔账本、人物/组织/地点档案、公共经验 |

## 二、目录结构

```text
世界观工坊\
  docs\lore\         设定长文（规则/体系/真相/团本设计）
  docs\档案\         人物 / 组织 / 地名 / 小神 / 聚落 / 碎片 / 地点
  docs\故事\         场景与章节正文
  docs\术语表.md     专有名词登记表

  tests\lore-check.test.mjs 门禁自身测试
  .foreman\gates.json       注册 gate-lore
```

## 三、格式约定（执笔者必读）

### 1. 档案标题（=全库唯一 + 术语表登记）

```text
# 小神：铁锈      ← 类别前缀 + 词条名
# 碎片：烬原
# 聚落：拾薪集
# 人物：老柯
# 地名：沉碑谷
```

规则：同类别同名词条**全库唯一**；人物/组织/地名/小神/聚落/碎片/地点必须登记进术语表。

### 2. @引用（三条铁律）

- **只写裸名**，不含类别前缀：`@引用:潮汐`，不写 `@引用:小神：潮汐`
- **目标必须是全库某文件的第一个 `# 标题`**（首行标题）
- **术语表登记 ≠ 可引用**：只有登记、没有条目文件的概念不能引用

### 3. 时间线

```text
一纪元-0-1 神战爆发
一纪元-末-1 众神陨落
二纪元-1-1 世界碎裂为碎片
```

行首 `纪元-年-月 事件`；全库按（纪元,年,月）**严格单调**，倒退报错；`末` = 纪元之末，排在所有数字之后。

### 4. 伏笔与回收 + 伏笔账本

- 埋：`[F7] 描述`；回收：`[R7] 描述`
- `[Fx]` 必须有 `[Rx]`（跨文件只配对、不排顺序）；**同一文件内** `[Rx]` 之后不得再引用同号 `[Fx]`
- 埋了但暂不回收的伏笔，必须登记进 `docs/伏笔账本.md`，否则报错
- 回收后从账本移除该行

### 5. 神域窄度（第六条）

小神档案必须有 `神域：X` 行；X 必须是**单一具体名词**，命中抽象大词黑名单（战争/智慧/命运/死亡/爱）报错。黑名单可按题材改。

### 6. 术语表

`| 词条 | 类别 | 定义 |`；新专名必须登记，否则 lore-check 报错。

## 四、流水线

```text
foreman_card upsert LORE-x（scopeDo/scopeNot/acceptance/gates=["gate-lore"]/allowedFiles=["docs/**","scripts/**","tests/**"]）
→ freeze（signedBy 主持）
→ 执笔者写内容
→ Builder：foreman_gate gate=gate-lore
→ 设定审查：foreman_verdict ACCEPT（首次自动开挑战）
→ 设定挑刺：foreman_challenge resolve cleared
→ 设定审查再 ACCEPT → 已验收
```

门禁实跑：`node scripts/lore-check.mjs`，exit 0 = 全库一致；报错格式 `docs/档案/xx.md:行号: 原因`，一步可定位。

## 五、测试剧情全记录（示例世界）

### 世界骨架

> **《神战之后》**：奇幻 · 严肃。一纪元众神为争夺「神名」互相撕扯，众神陨落；完整概念被撕成狭隘碎片，世界碎裂为碎片纪元。小神林立，凡人在碎片间求生。

### 神战真相（正典）

旧神之力来自**神名**（写在世界材质上的真言，神域是神名的延展）。神战起因=众神互夺神名；宽域被撕成窄域（锈、烬、回声、潮汐皆由此来）；陨落神祇的神名碎片+神躯残余凝成**神骸**（通货/借力燃料）；未参战者拾取窄域碎片立域，只能庇护领域内之事。

### 碎片与小神（1:1 骨架）

| 碎片 | 小神（神域） | 聚落 | 求生方式 |
|---|---|---|---|
| 烬原（灰烬平原） | 余烬 | 拾薪集 | 拾取余烬余温 |
| 空谷（回声不散） | 回声 | 余音集 | 靠回声维生 |
| 雾海（涨潮） | 潮汐 | 浮舟集 | 靠潮汐维生 |
| 边缘碎岸 | 铁锈 | 碎岸 | 边缘求生 |

### 求生规则与借力体系

- 通行：碎片边缘「裂隙」，渡舟以神骸为炉、借小神之力定向
- 贸易：神骸通货，四聚落计价
- 边境：碎片边界漂移，边境拾荒有风险
- 庇护：献贡物换「庇护契约」；**恩惠**（日常小力，折一件神骸）自动生效；**神迹**（大力，三件神骸+一段记忆）需重贡、一次即止；借力不得超出神域

### 团本：沉碑谷

神战战场遗迹，众神真言刻碑之地。敌人=**碑傀**（残存神名碎片唤醒的守护者）；恩惠可牵制，击杀需神迹。三关：谷口·守碑傀 → 碑林·无碑傀（取拓片）→ 沉道·群碑傀；Boss=**碑傀·真言体**。入谷备九件神骸。目标=裂底主碑中的大神神名碎片。

小队：老柯（余烬，向导）/ 苏聆（回声，拓片解读）/ 阿渡（潮汐，渡舟）/ 铁牙（铁锈，战斗）。

### 故事与伏笔闭环

- 《拾薪集一夜》：老柯夜拾余烬余温，旧铁片上「写」上去的纹路 → 埋 **[F1]**（神战真相相关），登记伏笔账本
- 《沉碑谷》（团本实况）：四关打通，苏聆判读碑文 → **[R1]** 揭示「碑上真言是神名的残片」；老柯献出「旧铁片来历」的记忆为神迹代价；主碑启封，取回神名碎片；账本移除 F1

### 时间线（11 条，严格单调）

```text
一纪元-0-1 神战爆发 → 一纪元-末-1 众神陨落 → 二纪元-1-1 世界碎裂
→ 2-1 烬原显化 → 3-1 空谷回响 → 4-1 雾海涨潮 → 5-1 商路初开
→ 6-1 首个庇护契约生效 → 7-1 沉碑谷裂隙现世 → 8-1 团本开放 → 9-1 主碑启封
```

## 六、门禁七类检查速查

| # | 检查 | 报错示例 |
|---|---|---|
| ① | 词条标题全库唯一 | `重复：烬原 先定义于…` |
| ② | 时间线单调 | `时间线倒退：…` |
| ③ | 伏笔 F/R 配对 + 账本登记 + 同文件顺序 | `伏笔 [F1] 未回收，且未登记进伏笔账本` |
| ④ | @引用 目标存在 | `docs/档案/xx.md:8: @引用:渡舟人 指向的条目不存在（目标须为文件首标题，术语表登记不算）` |
| ⑤ | 词条已登记术语表 | `未在术语表登记：…` |
| ⑥ | 小神神域窄度 | `神域：战争 命中抽象大词黑名单` |
| ⑦ | 长段落近似复读（≥60 字、相似 ≥0.90） | `疑似复读：段落 X 与段落 Y 高度相似` |

## 七、通用性测试结论（2026-10-28）

- 陌生五席零回查旧对话，独立跑通一个聚落条目（LORE-13）：**通用性 PASS**
- 回执发现的问题已全部修复：@引用 三句铁律、报错路径带 docs/ 前缀、跨文件 F→R 判序修正、ACCEPT 受理文案、面板术语表、claimedSeats 语义
- 已知边界：gate-lore 只跑检查器不跑 node:test 套件（自测靠执笔者手工跑）；门禁判一致性、不判文学性；神域黑名单可按题材改
