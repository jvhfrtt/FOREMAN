# 示例世界 · 《神战之后》

> 一个完整示例，展示本模板的六条规则在真实写作里怎么用。想了解工具的完整流程请看 `世界观版使用说明.md`。

## 骨架（奇幻 · 严肃）

一纪元众神为争夺「神名」互相撕扯，众神陨落；完整概念被撕成狭隘碎片，世界碎裂为碎片纪元。小神林立，凡人在碎片间求生。

## 神战真相（正典条目）

旧神之力来自**神名**——写在世界材质上的真言，神域是神名的延展。神战起因=众神互夺神名；宽域被撕成窄域（锈、烬、回声、潮汐皆由此来）；陨落神祇的神名碎片+神躯残余凝成**神骸**；未参战者拾取窄域碎片立域，只能庇护领域内之事。

## 碎片 / 小神 / 聚落（1:1）

| 碎片 | 小神（神域） | 聚落 |
|---|---|---|
| 烬原 | 余烬 | 拾薪集 |
| 空谷 | 回声 | 余音集 |
| 雾海 | 潮汐 | 浮舟集 |
| 边缘碎岸 | 铁锈 | 碎岸 |

## 规则体系

- 通行：裂隙 + 渡舟（神骸为炉、借小神之力定向）
- 贸易：神骸通货
- 庇护契约 → 恩惠（日常小力，折一件神骸）/ 神迹（大力，三件神骸+一段记忆，一次即止）
- 借力不得超出神域（窄度规则的可写场景）

## 团本：沉碑谷

危险区（碑林沉入裂隙）+ 敌人碑傀（残存神名碎片唤醒的守护者）。三关+Boss 真言体；入谷备九件神骸；目标=取回大神神名碎片。

小队：老柯（余烬·向导）/ 苏聆（回声·拓片）/ 阿渡（潮汐·渡舟）/ 铁牙（铁锈·战斗）。

## 故事弧（伏笔闭环示例）

1. 《拾薪集一夜》：老柯旧铁片纹路 → 埋 **[F1]**（神战真相），登记账本
2. 《沉碑谷》：团本实况，苏聆判读碑文 → **[R1]** 揭示真相一角；老柯献出旧铁片来历记忆；取回神名碎片；账本移除 F1
3. 《烬原长风》（万字正文）：余波——老柯忘了铁片来历，碎片夜夜低语 → 埋 **[F2]**，登记账本待回收

## 时间线（严格单调）

```text
一纪元-0-1 神战爆发 → 一纪元-末-1 众神陨落 → 二纪元-1-1 世界碎裂
→ 2-1 烬原显化 → 3-1 空谷回响 → 4-1 雾海涨潮 → 5-1 商路初开
→ 6-1 首个庇护契约生效 → 7-1 沉碑谷裂隙现世 → 8-1 团本开放 → 9-1 主碑启封
```

## 这个示例演示了什么

- ①标题唯一：碎片/小神/聚落/人物各不重名
- ②时间线单调：11 条里程碑逐年推进，含「末」纪元
- ③伏笔账本：F1→R1 闭环，F2 在账
- ④引用：跨 40 个文件的全引用网
- ⑤术语表：每个专名都有登记
- ⑥神域窄度：四小神的神域全是单一具体名词
