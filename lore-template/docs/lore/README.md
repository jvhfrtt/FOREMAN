# 世界观长文格式

`docs/lore/` 放设定长文（种族/纪元/力量体系/势力等），每个文件一个条目。

## 规则

- 文件首个 `# ` 标题即条目标题，可被 `@引用:<词条名>` 引用。
- `@引用:` 只写裸名，不含类别前缀（如 `@引用:潮汐`，不写 `@引用:地名：潮汐`）。
- 引用目标必须是全库某文件的**首行标题**（首个 `# ` 标题）；术语表登记 ≠ 可引用：
  没有条目文件的概念不能引用。
- 时间线条目每行一条，行首格式 `纪元-年-月 事件描述`（可带 `- ` 列表前缀）；
  年或月可为「末」（纪元之末）；全库按文件名字典序串联后，按（纪元,年,月）单调不倒退；
  纪元名按字典序，同年月可并列多条。
- 伏笔/回收（`[Fn]` / `[Rn]`）与 `@引用:` 规则同 `docs/档案/README.md`（未回收伏笔须登记 `docs/伏笔账本.md`）。
- 代码围栏（```）内的行不参与检查。
- 防复读（⑦）：同一文件内，去空白与标点后长度 ≥60 字符的两段，bigram 相似度 ≥0.90 视为疑似复读报错；
  短句、对话、叠词不误伤；标题行与代码围栏不参与；v1 只比同文件内段落，跨文件后续可加。

## 示例

```
星历-1024-07 风眼出现
星历-末-01 纪元终结
```
