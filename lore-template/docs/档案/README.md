# 档案条目格式

`docs/档案/` 下每个文件一个条目：人物 / 组织 / 地名 / 小神 / 聚落 / 碎片 六类命名条目，另接受时间线文件。

## 规则

- 文件首个 `# ` 标题即条目标题。命名条目标题为 `# 人物：<名>`、`# 组织：<名>`、`# 地名：<名>`、
  `# 小神：<名>`、`# 聚落：<名>`、`# 碎片：<名>`；`<名>` 全库唯一，且必须已在 `docs/术语表.md` 登记。
- 小神条目必须含一行 `神域：单一具体名词`：一个词（不含空白），不得使用抽象大词
  （黑名单：战争/智慧/命运/死亡/爱）。
- 正文引用其他条目用 `@引用:<词条名>`，目标词条（全库任意文件的首个标题）必须存在。
- `@引用:` 只写裸名，不含类别前缀（如 `@引用:潮汐`，不写 `@引用:小神：潮汐`）。
- 引用目标必须是全库某文件的**首行标题**（首个 `# ` 标题）；术语表登记 ≠ 可引用：
  没有条目文件的概念不能引用。
- 伏笔用 `[Fn]`（n 为数字），回收用 `[Rn]`：每个 F 必须有同号 R，同一文件内 R 出现之后
  不得再引用同号 F（跨文件只做配对，不做顺序）。
- 未回收的伏笔必须登记进 `docs/伏笔账本.md`（每行 `[Fn] 一句话描述`），回收后可移除该行；
  已有同号 `[Rn]` 的伏笔不受账本限制（账本可有可无）。
- 时间线条目行首格式 `纪元-年-月 事件`，年或月可为「末」（纪元之末）；全库按文件名字典序
  串联后按（纪元,年,月）单调不倒退。
- 代码围栏（```）内的行不参与检查，示例可放围栏内。
- 防复读（⑦）：同一文件内，去空白与标点后长度 ≥60 字符的两段，bigram 相似度 ≥0.90 视为疑似复读报错；
  短句、对话、叠词不误伤；标题行与代码围栏不参与；v1 只比同文件内段落，跨文件后续可加。

## 示例

```
# 小神：某某

神域：某某之物

@引用:某地名
[F1] 埋下一个谜团。
[R1] 回收这个谜团。
```
